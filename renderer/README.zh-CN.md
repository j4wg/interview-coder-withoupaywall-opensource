# Create React App 入门

本项目通过 [Create React App](https://github.com/facebook/create-react-app) 引导创建。

> **语言 / Language**：[English](README.md) | **简体中文**

## 可用脚本

在项目目录下，你可以运行：

### `npm start`

以开发模式运行应用。\
打开 [http://localhost:3000](http://localhost:3000) 在浏览器中查看。

你修改代码后页面会自动重新加载。\
控制台中也会显示任何 lint 错误。

### `npm test`

以交互式 watch 模式启动测试运行器。\
详见[运行测试](https://facebook.github.io/create-react-app/docs/running-tests)一节。

### `npm run build`

以生产模式构建应用到 `build` 文件夹。\
它会在生产模式下正确打包 React，并针对最佳性能进行优化。

构建产物经过压缩，文件名中包含哈希值。\
你的应用已经可以部署了！

部署详情请见[部署](https://facebook.github.io/create-react-app/docs/deployment)一节。

### `npm run eject`

**注意：这是单向操作。一旦执行 `eject`，就无法回退！**

如果你对构建工具与配置选项不满意，可以随时执行 `eject`。该命令会移除项目中的单个构建依赖。

它会将所有的配置文件和传递依赖（webpack、Babel、ESLint 等）直接复制到你的项目中，让你完全掌控它们。除 `eject` 之外的所有命令仍可正常使用，这些命令会指向复制出来的脚本，你可以按需调整。此时就需要你自己维护了。

你完全不必使用 `eject`。精心整理的功能集适用于中小型部署，你也不必因为使用了这项功能而感到负担。
